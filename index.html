Ultra Motherload Help

Welcome to Ultra Motherload. Ultra Motherload is a map editor for the game Super Motherload, published by XGen Studios. It allows you to view and edit the contents of your map files, and make any changes quickly and simply. You could create some cool patterns with the materials, give yourself a bit of a boost, or even create a maze or some other kind of challenge!

How do I select and edit tiles?

Drag across the map to select a rectangle of tiles. Dragging again replaces that selection. Click a tile to start a new selection on that tile. Hold Control and click to add or remove individual tiles. Hold Shift and click to add the rectangle between the last selected tile and the one you click.

Select only changes the selection. Overwrite uses the same gestures, then paints the resulting selection with the current material. A click paints that one tile. Control-click adds or removes a tile and paints whatever remains selected. Copy keeps the selection as the source; click the map to place the paste preview. Badges mark the copy and paste regions. Paste writes those tiles into the map.

Where are the map files stored?

The map files are stored in your user account's AppData folder:
%AppData%\XGen Studios, Inc\Super Motherload\savedata\worldXX\map

The map file has no extension, so when you're saving your changes, make sure the file is just called map. Even though the map file is edited locally, not uploaded, due to JavaScript sandboxing restrictions, the file will be "downloaded" when it is saved.

This means you may get a popup, or it may just save automatically in your downloads folder. Most browsers will also append a (1) to the end of the filename if it already exists, so remove this if you want to replace the original. The map file must be saved with the same name and in the same location as the original if you want to see your changes in-game, so it's recommended to keep a backup copy just in case.

How does the game order worlds, and why might a save disappear or show as CORRUPT?

Super Motherload discovers worlds by scanning for entries named savedata\world??. There are a few gotchas you might run into:

  • Dates and slot order come from the worldXX folder's Date Modified timestamp (newest first), not the folder number and not the map or progress file timestamps.
    • Replacing a map file in place does not update the parent worldXX folder's modified timestamp on Windows, so the world's displayed date and slot order in-game will not change.
  • Don't place loose backup files named worldXX directly in savedata.
    • The game's world?? scan does not check whether a match is a folder, so a file named e.g. world04 triggers a "Load World Save Data — An unknown I/O error occurred." popup and appears as a CORRUPT slot.
    • Always give backups an extension (such as .bak) or keep them outside savedata (note that Steam Cloud syncs everything inside savedata).
  • Identical folder timestamps hide worlds.
    • The game sorts discovered worlds in a set keyed solely by the folder's modified timestamp, so if two worldXX folders share the exact same timestamp (for example after a Steam Cloud sync or a timestamp-preserving backup restore), the duplicates are silently hidden until their folder timestamps differ.
    • Simply renaming a folder does not update its own Date Modified timestamp—instead, create and delete a temporary file inside the hidden worldXX folder (or change its timestamp via PowerShell / touch).
Why can't I see my changes in-game?

First of all, make sure you have saved the map file in the correct location, as explained above. If the game is running, you will need to exit to the main menu and reload the map. It is not recommended to change the map file while it is open in the game, quit to the main menu first before performing changes.

Why are some tiles locked? What is Safe Mode?

Some tiles are locked because they have special meaning within the game. Tiles that lie within outposts, the final boss room, or act as markers shouldn't be edited, as they could cause problems in the game, like the final boss fight not starting properly, or the game crashing. Disabling Safe Mode unlocks outpost and invisible barrier tiles for editing, and also reveals the Experimental section in the material picker (Dirt (edge B), Speed Boost, Blueprints, and Out of Bounds). Use them at your own risk, as they may behave unexpectedly or corrupt your progress. You have been warned.

Why is there a row of invisible barriers at the top of the map?

You have discovered the secret sky shop! This shop allows you to buy more upgrades to your vehicle than the shops in the outposts. To access the sky shop, you must fly all the way up and to the left of the map, then drive along the invisible barrier to the far right.

What is Safe Mode?

Safe Mode (On) protects special tiles that have gameplay meaning so you don't accidentally break your world:

  • Locks outpost areas, the final boss room, and invisible barriers (including the secret sky shop floor).
  • Hides unused/experimental tile types from the material picker.

Safe Mode (Off) lets you edit outposts and invisible barriers, and reveals the Experimental category in the material picker (Dirt (edge B), Speed Boost, Blueprints, and interior Out of Bounds tiles). The outer map perimeter remains locked to keep the file playable.

Editing protected tiles or placing experimental tiles can cause unexpected behaviour in Super Motherload—keep a backup copy of your map file before disabling Safe Mode.
